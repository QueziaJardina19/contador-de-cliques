# Contador de Cliques Básico

Este projeto é uma aplicação React simples que implementa um contador de cliques.

## Como funciona

- O aplicativo exibe o valor atual do contador.
- Cada vez que o botão é clicado, o contador é incrementado em 1.

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm start
```

3. Abra o navegador em http://localhost:3000

## Tecnologias usadas

- React
- React DOM
- Create React App (react-scripts)
